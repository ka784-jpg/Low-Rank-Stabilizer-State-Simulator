# Figure-to-code map

Source: [arXiv:2508.20252, version 3](https://arxiv.org/html/2508.20252v3). Figure numbering follows that version. This map is an audit of **available code**, not a claim that published datasets have been reconstructed.

The paper's single-pair all-to-all circuit starts from `|+>^L`, runs `2L^2` steps, and at each step attempts one random-pair CZ with probability `1/2`, a random-site T with `pT=eta/L^beta`, and a random-site projective measurement with probability `pm`. For the Z-only model, a measured qubit is reset to `|+>` afterward. The X-only model does not reset. These are not the later brickwork, open-boundary MPS circuits in other projects.

## Method notes

- The original LRSD file is an extensionless Julia source. The new Fig. 3/4 driver includes it without changing its name. Its `compute_logno` routine returns one logical-term count and runtime per trajectory. The driver records `eta`, `beta`, `pm`, `cutoff`, `basis`, and a parameter-point seed.
- The original Bell file is also extensionless Julia source. Its `gen_circuit` and `runy` routines implement the Z-basis terminal-T construction and sample `4L` Bell outcomes per trajectory before computing a stabilizer-nullity estimate. `scripts/fig6_bell_magic.jl` records those estimates; `bell_samples=4L` is **sampling effort**, not a count of distinct samples.
- The dense ancilla reference builds the full two-qubit Clifford group modulo global phase (11,520 elements), samples its elements uniformly for the system-only scrambling stage, entangles an ancilla with one random system qubit, and evolves the same random-pair CZ/T/X-measurement circuit. `S_Q` is the von Neumann entropy of the reduced ancilla, not purification of a generic mixed state. Its memory scales as `2^(L+1)`.
- For the ancilla fit, all intervals with `t_end-t_start >= L^2/8` and terminal `SEM/mean < 0.35` are searched. An unweighted straight-line fit of `log(mean S_Q)` against time supplies `tau=-1/slope`; the eligible interval with the highest `R^2` is retained. This follows the stated Appendix B window selection, but additional statistical choices in the original plotting pipeline are not available.
- A seed permits rerunning a parameter point in the same Julia implementation. Paired cutoff runs reset to the same RNG seed, but cutoff-dependent code paths may consume random draws differently; this **does not guarantee identical circuit records**. Exact paired-circuit reproducibility for Fig. 3 requires explicit circuit-record generation and replay, which is not yet implemented.

## Validation and limitations

`test/runtests.jl` checks the Clifford-group size/unitarity, absence of ancilla purification without measurement, repeatability, a synthetic exponential fit, and zero nullity in a no-T Clifford circuit. The supplied examples are quick smoke runs. They are **not** numerical replication of the paper's plotted values, uncertainty bars, critical exponents, or large-system statistics. In particular, the large-L LRSD ancilla algorithm, cutoff-dependent nullity, exact paired circuit replay, and several appendix observables still need dedicated implementation and cross-checks before a complete reproduction claim can be made.
